# limbo-c++ — lightweight Minecraft Limbo backend (C++20)

Behind-proxy Limbo. Proxy owns auth/version translation where possible.
See `docs/research/limbo-references.md` for protocol sources and `docs/ARCHITECTURE.md` for decisions.

## Supported versions

All Java release PVNs 47 (1.8.x) through 775 (26.1). Exact per-version packet
IDs verified against minecraft-data `protocol.json` (exact-minor dirs) and
proven live with real `minecraft-protocol` clients holding 15s in Play on
1.8.8, 1.12.2, 1.13.2, 1.14.4, 1.15.2, 1.16.5, 1.17.1, 1.18.x, 1.19–1.19.4,
1.20.1, 1.20.2, 1.20.5, 1.21.1, 1.21.2, 1.21.4, 1.21.5. Above 775: clean
"Unsupported Minecraft version" Login disconnect.

## Build (no sudo, no cmake needed)

Requires: `g++ >= 12`, `make`, OpenSSL libcrypto (headers + `.so.3`).

```sh
make            # builds build/limbo
make test       # 12 unit suites + HMAC vector (must all pass)
./build/limbo --config config/limbo.properties
```

## Config

`config/limbo.properties` (key=value):

```
bind=0.0.0.0            # 0.0.0.0/:: (dual-stack), IP literal, or hostname
port=25566
max_players=100
version_name=Limbo-C++
motd=Limbo
forwarding=NONE|MODERN  # MODERN requires forwarding_secret (velocity.toml)
forwarding_secret=
read_timeout_ms=30000
max_packet_bytes=8192
schematic_path=         # "" = void; else .schem v2 pasted at spawn (1.18+ render)
```

## Behavior

- Status ping, offline direct login, Velocity MODERN forwarding (HMAC-SHA256,
  constant-time compare, versions 1..4, IPv6 `%zone` stripped).
- Play: JoinGame (real per-era registry codecs from minecraft-data) →
  Abilities → Position → GameEvent13 (1.20.3+) → Center → void/paste chunk(s)
  → KeepAlive loop. Movement ignored, 30s echo timeout.
- Configuration (1.20.2+): real RegistryData + Finish, tolerates early
  Settings and stragglers, bounded by readTimeoutMs.
- .schem v2 spawn paste (shape-preserving stone/air on 1.18+, void elsewhere
  and on any load error). Full palette mapping deferred (see ARCHITECTURE).
- Abuse guards: per-connection token buckets (500 pkt/s, 16KB/s), frame caps,
  max players, clean disconnects. Fuzz-tested, no crash/hang.

## Testing

- `make test`: 12 C++ suites + Python HMAC vector.
- `tests/integration/matrix.py`: status+login→Play across all 41 release PVNs.
- `tests/integration/hardening_matrix.py`: 40 rejection-path checks.
- `tests/fuzz/fuzz_suite.py` (31 cases) + `fuzz_packet.py`: no crash, liveness kept.
- `tests/soak/soak.py`: 300 idle holders/60s (see results in ARCHITECTURE).
- Real clients: `minecraft-protocol` bots join + hold 15s per era (see above).
- Registry/codec blobs: generated by `tools/gen_codec.py` from
  minecraft-data `loginPacket.json` (checked-in output in
  `src/protocol/codec_data.*`).
